# CriticalFlow

基于本地大语言模型的智能项目管理 Agent。只需一段自然语言描述，系统即可自动帮你建图、计算关键路径（AOE 网），并使用蒙特卡洛模拟给出项目延期风险的概率。全程本地运行，数据不出电脑。

## 技术架构

本项目采用了极度注重性能的“跨语言同进程”混合架构：
* **界面与核心引擎**：Rust (egui 渲染 UI + 原生图论算法计算)
* **大模型与风险模拟**：Python (调用本地 OMLX 接口 + NumPy 向量化运算)
* **通信桥梁**：PyO3 (Rust 直接在进程内唤醒 Python，零网络 I/O 损耗)

## 快速开始

### 1. 环境依赖
确保你的系统（macOS 或 Linux）已安装以下工具：
* Rust 工具链
* Python 3.12
* `uv`（极速 Python 包管理器）

### 2. 配置 Python 环境
在项目根目录下执行以下命令，完成虚拟环境创建和依赖安装：
